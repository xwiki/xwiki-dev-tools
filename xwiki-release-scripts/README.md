# Scripts used to release XWiki

* `list_contributors.sh`: list the contributors (authors and co-authors of commits) of XWiki Commons, Rendering and Platform between two versions, see `list_contributors.sh` without arguments for more details.
* `release-note-scripts/publish_contributors.py`: publish these contributors, without bots, to the "Contributors" entry of the corresponding release note on xwiki.org, see `publish_contributors.py -h` for more details.
